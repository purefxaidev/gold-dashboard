# ตั้งค่าสั่งเทรดด้วยเสียงจากหน้าโทร PUREGOLD

หน้าโทร https://purefxaidev.github.io/gold-dashboard/call.html จะส่งคำสั่งเทรดเข้าคิวใน Google Apps Script ของคุณเอง
แล้วระบบเทรดจะดึงคิวไปทำภายในราว 10 นาที และแจ้งผลกลับมาที่หน้าโทร
หน้าเว็บไม่มีรหัสหรือสิทธิ์เข้าบัญชี Exness และไม่มีค่าลับใดๆ อยู่ในเว็บหรือใน GitHub

ใช้เวลาประมาณ 5 นาที ทำบนคอมพิวเตอร์จะง่ายกว่า

## ขั้นที่ 1 วางโค้ด

1. เปิด https://script.google.com แล้วเข้าสู่ระบบด้วยบัญชี Google ของคุณ
2. ถ้ามีโปรเจกต์บอท LINE เดิมอยู่แล้ว ให้เปิดโปรเจกต์นั้น ถ้ายังไม่มี ให้กด โปรเจกต์ใหม่ แล้วตั้งชื่อ เช่น puregold-bot
3. เปิดไฟล์ Code.gs ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดใหม่ทั้งไฟล์จาก
   https://github.com/purefxaidev/gold-dashboard/blob/main/line-bot/Code.gs
   (กดปุ่ม Raw หรือปุ่มคัดลอกไฟล์ แล้ววาง)
4. กดบันทึก (Ctrl+S)
5. กดไอคอนเฟือง การตั้งค่าโปรเจกต์ แล้วตั้ง เขตเวลา เป็น Asia/Bangkok

## ขั้นที่ 2 ตั้งรหัสลับของระบบ (ALERT_SECRET)

ถ้าเคยตั้ง ALERT_SECRET ไว้แล้ว ข้ามขั้นนี้ได้

1. ที่แถบด้านบนของหน้าแก้โค้ด เลือกฟังก์ชัน makeAlertSecret แล้วกด เรียกใช้
2. ครั้งแรก Google จะขอสิทธิ์ ให้กด ตรวจสอบสิทธิ์ > เลือกบัญชีของคุณ > ขั้นสูง > ไปที่โปรเจกต์ > อนุญาต
3. ระบบจะสร้าง ALERT_SECRET แบบสุ่มเก็บไว้ใน คุณสมบัติของสคริปต์ ให้เอง

## ขั้นที่ 3 ตั้ง PIN เจ้าของ

PIN นี้ใช้ยืนยันตัวตนตอนสั่งเทรดจากหน้าโทร ระบบเก็บไว้แบบเข้ารหัส (hash) ไม่เก็บตัว PIN จริง

1. กดไอคอนเฟือง การตั้งค่าโปรเจกต์ > เลื่อนลงไปที่ คุณสมบัติของสคริปต์ > เพิ่มคุณสมบัติของสคริปต์
2. ชื่อ: OWNER_PIN_NEW   ค่า: PIN ที่ต้องการ อย่างน้อย 6 ตัว เช่น ตัวเลข 6 ถึง 8 หลักที่คนอื่นเดาไม่ได้ (ห้ามใช้วันเกิดหรือ 123456)
3. กด บันทึกคุณสมบัติของสคริปต์
4. กลับไปหน้าแก้โค้ด เลือกฟังก์ชัน setOwnerPin แล้วกด เรียกใช้
5. บันทึกการทำงานจะขึ้นว่า ตั้ง PIN เรียบร้อย ระบบจะลบ OWNER_PIN_NEW ทิ้ง และเก็บเป็น OWNER_PIN_HASH แทนให้เอง
6. ถ้าอยากเปลี่ยน PIN ภายหลัง ให้ทำขั้นที่ 3 ซ้ำ

ห้ามส่ง PIN ให้ใคร รวมถึงในแชทกับผม หน้าโทรจะถาม PIN ตอนส่งคำสั่งครั้งแรก และจำไว้แค่จนกว่าจะปิดแท็บนั้น

## ขั้นที่ 4 Deploy เป็นเว็บแอป

ถ้ายังไม่เคย deploy
1. กดปุ่ม ทำให้ใช้งานได้ (Deploy) มุมขวาบน > การทำให้ใช้งานได้รายการใหม่
2. กดเฟืองข้าง เลือกประเภท > เว็บแอป
3. เรียกใช้ในฐานะ: ฉัน
4. ผู้มีสิทธิ์เข้าถึง: ทุกคน
5. กด ทำให้ใช้งานได้ แล้วคัดลอก URL ของเว็บแอป ที่ลงท้ายด้วย /exec

ถ้าเคย deploy แล้ว (อยากได้ URL เดิม)
1. ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้
2. กดรูปดินสอ แก้ไข > ช่องเวอร์ชัน เลือก เวอร์ชันใหม่ > ทำให้ใช้งานได้
3. URL /exec จะเหมือนเดิม

ทุกครั้งที่แก้โค้ด ต้องทำ เวอร์ชันใหม่ ไม่อย่างนั้นเว็บแอปจะยังใช้โค้ดเก่า

## ขั้นที่ 5 ใส่ URL ในหน้าโทร

ทำบนมือถือที่จะใช้โทร
1. เปิด https://purefxaidev.github.io/gold-dashboard/call.html ใน Chrome หรือ Safari (ไม่ใช่ในแอป LINE)
2. แตะหัวข้อ คำสั่งเทรดด้วยเสียง (เฉพาะเจ้าของ)
3. วาง URL /exec ลงในช่อง แล้วกด บันทึก URL
4. สถานะจะขึ้นว่า ตั้งค่าแล้ว

URL นี้เก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ถ้าใช้หลายเครื่อง ต้องใส่ทีละเครื่อง

## ขั้นที่ 6 ส่ง URL และ ALERT_SECRET ให้ผม

ระบบเทรดของผมต้องใช้สองค่านี้เพื่อดึงคิวคำสั่งและรายงานผล
1. URL /exec จากขั้นที่ 4
2. ค่า ALERT_SECRET ดูได้ที่ การตั้งค่าโปรเจกต์ > คุณสมบัติของสคริปต์

บอกผมในแชทว่า พร้อมส่งค่าแล้ว ผมจะเปิดช่องกรอกค่าลับให้ ให้วางค่าในช่องนั้นเท่านั้น
อย่าพิมพ์ ALERT_SECRET ลงในข้อความแชทปกติ ผมจะเก็บเป็น LINE_ALERT_URL และ ALERT_SECRET ในเครื่องระบบเทรด ไม่ขึ้นเว็บหรือ GitHub

## วิธีใช้

1. กดโทรในหน้าโทร แล้วพูด เช่น "เปิด Sell ทอง 0.1 SL 4152 TP 4138" หรือ "ปิด Buy ทองทั้งหมด" หรือ "เลื่อน SL กันทุนทุกไม้"
2. AI จะทวนคำสั่ง แล้วหน้าจอจะขึ้นหน้าต่างยืนยัน แสดงคำสั่งเป๊ะๆ ทั้งไทยและอังกฤษ
3. ครั้งแรกให้ใส่ PIN แล้วกด ยืนยันส่งคำสั่ง ถ้าไม่ใช่สิ่งที่ต้องการ ให้กด ยกเลิก
4. ระบบเทรดจะทำคำสั่งภายในราว 10 นาที แล้ว AI จะแจ้งผลในสาย และขึ้นผลในหน้าจอ

## กติกาและความปลอดภัย

- ทองไม้ละ 0.1 ล็อต ทองรวมไม่เกิน 0.5 ล็อต เปิดไม้ใหม่ต้องมี SL และ TP ทุกครั้ง
- คำสั่งที่เกินกติกา ระบบเทรดจะขอยืนยันในแชทก่อนทำ ส่วนล็อตเกิน 1 ระบบไม่รับเลย
- ส่งคำสั่งได้ไม่เกิน 10 ครั้งต่อชั่วโมง
- ใส่ PIN ผิด 5 ครั้งติดกัน ระบบจะล็อก 60 นาที ถ้าเป็นคุณเองใส่ผิด ปลดล็อกได้โดยเลือกฟังก์ชัน unlockWebCmd ใน Apps Script แล้วกด เรียกใช้
- ถ้าสงสัยว่า PIN หลุด ให้ตั้ง PIN ใหม่ตามขั้นที่ 3 ทันที
- ระบบคำสั่งนี้ใช้กับ Apps Script เท่านั้น ยังไม่รองรับ Cloudflare Worker
